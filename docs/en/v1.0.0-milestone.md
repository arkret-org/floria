## Local Exit Checks

Before using this record for a release candidate, run:

```powershell
cargo fmt --check
cargo check
cargo test --lib
python -m json.tool docs/en/openapi.json > $null
```

The long-running soak and Redis-backed dedup TTL tests are committed as ignored
tests because they require explicit local capacity and/or Redis. Run them when
the matching environment is available.
